# Критерий готовности — проверка верификатором

Проверку делает отдельный проход, который видит только артефакты и итоговую
структуру, но не рассуждения, по которым она собиралась. Каждый пункт —
«да» с доказательством или «нет» с конкретной строкой.

## 1. Структура заполнена

- [ ] У каждой страницы заполнены все колонки: уровень, У/Т/С, ядро/масштаб,
      раздел, название, что на странице, зачем нужна, обоснование.
- [ ] Тип У/Т/С поставлен по `categories.md`, а не на глаз.
- [ ] «Зачем нужна» формулируется одной фразой. Не формулируется — странице
      не место в ядре.

## 2. Обоснование прослеживается

- [ ] У каждой страницы есть обоснование одного из трёх видов: спрос с цифрой
      и датой / есть у лидеров выдачи / закон-техника-интеграция.
- [ ] **Каждая цифра спроса совпадает с артефактом спроса дословно** — и фраза,
      и число. Проверять скриптом, не глазами: обрезанная цитата выглядит
      правдоподобно и не сходится с источником.
- [ ] Каждое обоснование ссылается на файл-сырьё: `(01)`, `(02)`, `(03)`, `(04)`.

## 3. Выдача снята честно

- [ ] Проверено минимум 5 запросов с регионом клиента.
- [ ] Зафиксированы минимум 2 настоящих конкурента и их структуры.
- [ ] Для Google записана страна выхода. Запросы без названия места в тексте,
      снятые не из нужной страны, не засчитаны.
- [ ] Реклама и локальный пак, снятые с чужого IP, не засчитаны.

## 4. Деление на волны

- [ ] Страницы разнесены на ядро и масштабирование.
- [ ] В ядре нет страниц «клиент захотел» без данных или технической причины.
- [ ] Срезы спроса разной географии (предтрип / в-маркете) не сложены.

## 5. Служебные страницы

- [ ] Посчитаны минимум: политика ПДн, согласие, cookie, 404, оферта — если
      есть онлайн-заявка или оплата.

## 6. Итог сходится

- [ ] Структура сводится в формулу «X уникальных + Y типовых + Z служебных»
      отдельно для ядра и для масштабирования.
- [ ] Ядро + масштабирование = общее число строк.
- [ ] Значения типа и волны — ровно из списков калькулятора.

## 7. Ничего не потеряно

- [ ] Пожелания клиента либо вошли в структуру, либо записаны в вопросы к брифу.
- [ ] Всё непокрытое (не снятый срез, недоступный источник) записано в файл
      разведки как непокрытое, а не подменено имеющимися данными.

## Итог проверки

Верификатор возвращает список нарушений с номером строки. Агент исправляет
и прогоняет проверку заново. Разведка готова, когда нарушений ноль.
