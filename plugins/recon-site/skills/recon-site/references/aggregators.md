# Классификация выдачи

Каждая позиция топа относится к одному из четырёх типов. Доля первых трёх —
главная цифра разведки: она показывает, сколько места в выдаче вообще
доступно сайту клиента.

| Тип | Что это | Вывод для КП |
|---|---|---|
| `сервис` | собственный сервис поисковика | место недоступно в принципе |
| `агрегатор` | классифайд, каталог, маркетплейс | пробиться почти нельзя, надо быть внутри |
| `рейтинг` | подборка «топ-10 лучших» | попадать через размещение, не через SEO |
| `сайт` | настоящий сайт компании | вот здесь идёт борьба |

Отдельно помечать `сайт`, у которого адрес вида `/khabarovsk/`, `/phuket/`
и в структуре есть ещё города: это **городская посадочная федеральной или
международной сети**, а не локальный конкурент. Вывод для клиента другой:
против сети с сотней посадочных бороться дороже. `competitor.py` проверяет
это автоматически.

## Сервисы поисковиков

```
uslugi.yandex.ru  yandex.ru/maps  yandex.ru/products  market.yandex.ru
travel.yandex.ru  google.com/maps  google.com/travel  google.com/shopping
```

Признак в Google: локальный пак (карта с тремя карточками), Shopping,
блок «Отели»/«Аренда» — это места поисковика, не органика.

## Медицина и здоровье

В медицинских нишах эти площадки занимают верх выдачи почти всегда — по
замеру в Хабаровске 77% топ-10 по запросам «специальность + город».
Пробиться между ними можно на 2–3 места, поэтому размещение внутри
агрегатора здесь не «в дополнение к SEO», а часто основной канал.

```
prodoctorov.ru  napopravku.ru  docdoc.ru  doctu.ru  sberhealth.ru
krasotaimedicina.ru  medbooking.com  infodoctor.ru  meds.ru
gorzdrav.org  medportal.ru  doctorpiter.ru  03.ru  medaboutme.ru
zdravcity.ru  eapteka.ru  apteka.ru  vseoperacii.com
```

Городские поддомены (`hab.docdoc.ru`, `khv.*`) распознаются автоматически:
проверка идёт и по самому домену, и по его поддоменам.

## Тревел и аренда авто

Актуально для проектов вроде проката машин, трансферов, экскурсий.

```
rentalcars.com  discovercars.com  economybookings.com  localrent.com
myrentacar.com  getransfer.com  kiwitaxi.ru  12go.asia  bookaway.com
klook.com  getyourguide.com  viator.com  tui.*  level.travel
```

Русскоязычные площадки и форумы, куда уходит туристический спрос:
```
forum.awd.ru  awd.ru  vinskiy.ru  t.me  vk.com  pikabu.ru
```

Телеграм-каналы и чаты в туристических нишах часто забирают больше
трафика, чем сайты. Если в выдаче или в разговоре с клиентом всплывают
`t.me` — фиксировать отдельной строкой: это канал продаж, который сайт
не заменит, но может подпитывать.

## Как считать

1. Взять топ-10 по каждому запросу.
2. Проставить тип каждой позиции.
3. Доля = (сервисы + агрегаторы + рейтинги) / всего позиций.
4. Записать, сколько осталось на настоящие сайты и кто именно эти сайты.

Ориентир: 70%+ занятого топа — SEO как основной канал под вопросом, и это
честный аргумент в КП, а не повод замолчать. Ниже 50% — пробиваемо.

Список доменов заведомо неполный. Домена нет в списке — смотреть на сайт:
если он продаёт чужие услуги списком, это агрегатор, как бы ни назывался.
