# Классификация страниц: У / Т / С и ядро / масштабирование

Классификация напрямую определяет смету: калькулятор считает деньги по
счётчикам уникальных, типовых и служебных страниц.

## Тип страницы

| Тип | Определение | Проверочный вопрос | Признак ошибки |
|---|---|---|---|
| **У — уникальная** | Своя страница с собственным дизайном и уникальным содержанием | «Нужен ли этой странице отдельный макет?» — да | Уникальной названа страница, которую можно собрать из шаблона другой |
| **Т — типовая** | Страниц несколько, структура одна, контент разный: карточки, разделы каталога, районы, статьи | «Можно ли сделать один шаблон и размножить?» — да | Типовыми названы страницы с разной логикой блоков — один шаблон не выйдет |
| **С — служебная** | Техническая или юридическая страница без продающей функции | «Страница нужна закону или технике, а не продаже?» — да | Юрстраницы забыты вовсе — их 4–7 почти на любом сайте |

**Спорный случай между У и Т — считать У.** Лишний макет в смете дешевле,
чем бесплатная переделка после подписания договора.

Хаб раздела (список районов, список статей) — обычно **У**, а сами
страницы внутри — **Т**.

## Служебный минимум

Проверить, что посчитаны:
- политика обработки персональных данных;
- согласие на обработку персональных данных;
- уведомление о cookie;
- публичная оферта / правила — если есть онлайн-заявка или оплата;
- страница 404.

## Ядро или масштабирование

| | Ядро | Масштабирование |
|---|---|---|
| Что это | продаём сейчас, первый запуск | после запуска, под подтверждённый спрос |
| Критерий | есть спрос с цифрой, есть у лидеров выдачи, или требует закон/техника | спрос есть, но услуга новая, направление не решено или спрос небольшой |
| Решает | данные разведки | клиент — если это расширение услуги |

В ядре не должно быть страниц «клиент захотел» без данных или технической
причины. Такие пожелания уходят в вопросы к брифу.

Расширение услуг (новое направление бизнеса, другой язык, соседний рынок) —
всегда решение клиента. До его ответа такие страницы по умолчанию идут в
масштабирование, а в КП превращаются в вилку «базовый запуск / полный объём».

## Обоснование

У каждой страницы — одно из трёх:
- `спрос N/мес` — цифра из артефакта спроса, с датой замера;
- `есть у лидеров выдачи` — с названием конкурентов;
- `закон` / `техника` / `интеграция`.

Нет ни одного — страница помечается `гипотеза`. Выдумывать цифру нельзя.

## Значения для калькулятора

Лист «0. Структура сайта» принимает значения **только из выпадающих
списков**. Текст мимо списка молча выбрасывает страницу из счётчиков.

- тип: ровно `У`, `Т`, `С`;
- волна: ровно `ядро`, `масштабирование`.

Колонка «Обоснование» — рабочая, в калькулятор не переносится.
